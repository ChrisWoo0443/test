Create a Spotify App

You need a free Spotify Developer app to connect. This takes about 2 minutes.

Open Spotify Dashboard
1
Sign in and click Create App
2
Give it any name — e.g. My G2 Music
3
Under Redirect URIs, add exactly:
http://localhost:3001/auth/callback
4
Check Web API under APIs used
5
Click Save
